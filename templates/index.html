ANALYST NOTES

How to interpret this view

  • Blast radius: nodes reachable within three relationship hops.
  • Attack path: shortest undirected path — not proof of exploitability.
  • Choke point: high betweenness may connect otherwise separate areas.
  • Shadow Graph: directed discovery simulation only.
  • Blast Shield: in-memory what-if; never changes real systems.
Production use would require authenticated telemetry, time-aware edges, access-control semantics, and security testing.
